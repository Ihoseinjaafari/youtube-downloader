# YouTube Downloader - دانلودر یوتیوب

یک ابزار کامل و حرفه‌ای برای دانلود ویدیو، صدا و پلی‌لیست از یوتیوب با رابط وب مدرن و فارسی.

![Python](https://img.shields.io/badge/Python-3.7+-blue.svg)
![License](https://img.shields.io/badge/License-MIT-green.svg)

---

## ✨ ویژگی‌ها

- 🎬 **دانلود ویدیو** با کیفیت‌های مختلف (Best, 720p, 480p, 360p)
- 🎵 **استخراج صدا** به فرمت‌های MP3 و M4A
- 📋 **دانلود پلی‌لیست** - دانلود کامل پلی‌لیست‌های یوتیوب
- 📝 **زیرنویس** - استخراج زیرنویس به زبان‌های مختلف (فارسی، انگلیسی، عربی و...)
- 🌐 **رابط وب** - طراحی مدرن، زیبا و کاملاً فارسی
- 🔍 **پیش‌نمایش** - نمایش اطلاعات ویدیو، تامبنیل و کیفیت‌های موجود قبل از دانلود
- 🔄 **وضعیت زنده** - مشاهده پیشرفت دانلود به صورت درصد و سرعت
- 📜 **تاریخچه** - مدیریت و مشاهده دانلودهای انجام شده
- ⚡ **چند منظوره** - دانلود همزمان چندین ویدیو
- 🔐 **پشتیبانی از کوکی** - امکان دانلود ویدیوهای محدود شده
- 🚀 **اجرای خودکار** - باز شدن خودکار مرورگر پس از اجرا

---

## 📦 پیش‌نیازها

- **Python 3.7** یا بالاتر
- **ffmpeg** (برای ادغام ویدیو و صدا)

### نصب ffmpeg

**لینوکس (Ubuntu/Debian):**
```bash
sudo apt update
sudo apt install ffmpeg
```

**مک (macOS):**
```bash
brew install ffmpeg
```

**ویندوز:**
1. دانلود از [ffmpeg.org](https://ffmpeg.org/download.html)
2. اضافه کردن به PATH سیستم

## 💻 نحوه استفاده

### اجرای برنامه وب

```bash
python web_downloader.py
```

پس از اجرا:
1. برنامه به صورت **خودکار مرورگر شما را باز می‌کند**
2. اگر باز نشد، به آدرس `http://localhost:5000` بروید

### مراحل دانلود

1. **وارد کردن لینک** - لینک ویدیو یا پلی‌لیست یوتیوب را کپی کنید
2. **بررسی لینک** - روی دکمه 🔍 **"بررسی لینک و نمایش کیفیت‌ها"** کلیک کنید
   - نمایش تامبنیل، عنوان، نام آپلودر و مدت زمان
   - تشخیص خودکار پلی‌لیست و نمایش تعداد ویدیوها
   - نمایش کیفیت‌های موجود
3. **انتخاب فرمت** - کیفیت ویدیو یا فرمت صوتی مورد نظر را انتخاب کنید
4. **زیرنویس (اختیاری)** - زبان زیرنویس را انتخاب کنید
5. **پلی‌لیست** - اگر لینک پلی‌لیست است، تیک مربوطه فعال می‌شود
6. **شروع دانلود** - روی دکمه **"شروع دانلود"** کلیک کنید

---

## 🎯 فرمت‌های قابل دانلود

| فرمت | توضیحات | کاربرد |
|------|---------|--------|
| `best` | بهترین کیفیت ویدیو + صدا (MP4) | دانلود با بالاترین کیفیت |
| `720p` | کیفیت HD 720p | تعادل بین کیفیت و حجم |
| `480p` | کیفیت استاندارد 480p | حجم متوسط |
| `360p` | کیفیت پایین 360p | کمترین حجم |
| `mp3` | فقط صدا - 320kbps | موسیقی و پادکست |
| `m4a` | فقط صدا - فرمت M4A | کیفیت اصلی صدا |

## 🔧 عیب‌یابی

### ❌ خطای ffmpeg
**مشکل:** خطای مربوط به نبود ffmpeg  
**راه حل:**
```bash
ffmpeg -version  # بررسی نصب بودن
# اگر نصب نیست، طبق بخش پیش‌نیازها نصب کنید
```

### ❌ مشکل در دانلود پلی‌لیست
**راه حل‌ها:**
- مطمئن شوید لینک پلی‌لیست صحیح است (شامل `list=` باشد)
- تیک "دانلود به عنوان پلی‌لیست" را فعال کنید
- برخی پلی‌لیست‌ها ممکن است خصوصی یا محدود باشند

### ❌ باز نشدن مرورگر
**راه حل:** به صورت دستی به آدرس نمایش داده شده در ترمینال بروید (معمولاً `http://localhost:5000`)

### ❌ خطا در دانلود ویدیوهای محدود شده
**راه حل:** نیاز به تنظیم کوکی دارد (در حال توسعه)
