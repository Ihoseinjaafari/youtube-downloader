# YouTube Downloader - دانلودر یوتیوب

یک ابزار کامل برای دانلود ویدیو، صدا و پلی‌لیست از یوتیوب با رابط وب.

## ویژگی‌ها ✨

- 🎬 دانلود ویدیو با کیفیت‌های مختلف (Best, 720p, 480p, 360p)
- 🎵 استخراج صدا به فرمت‌های MP3 و M4A
- 📋 **دانلود پلی‌لیست‌های کامل یوتیوب**
- 📝 استخراج زیرنویس به زبان‌های مختلف (فارسی، انگلیسی، عربی و...)
- 🌐 رابط وب زیبا و فارسی
- 🔄 نمایش وضعیت دانلود به صورت زنده
- 📜 تاریخچه دانلودها
- 🔐 پشتیبانی از کوکی برای ویدیوهای محدود شده
- ⚡ دانلود همزمان چندین ویدیو

## پیش‌نیازها

- Python 3.7+
- ffmpeg (برای ادغام ویدیو و صدا)

### نصب ffmpeg

**لینوکس (Ubuntu/Debian):**
```bash
sudo apt update
sudo apt install ffmpeg
```

**مک:**
```bash
brew install ffmpeg
```

**ویندوز:**
دانلود از https://ffmpeg.org/download.html

## نصب

```bash
# کلون کردن ریپو
git clone <repository-url>
cd <repository-name>

# نصب وابستگی‌ها
pip install -r requirements.txt
```

## نحوه استفاده

### اجرای برنامه وب

```bash
python web_downloader.py
```

بعد از اجرا، برنامه به صورت خودکار مرورگر شما را باز می‌کند و می‌توانید:

1. لینک ویدیو یا پلی‌لیست یوتیوب را وارد کنید
2. **روی دکمه "بررسی لینک و نمایش کیفیت‌ها" کلیک کنید** تا اطلاعات ویدیو نمایش داده شود
3. فرمت مورد نظر را انتخاب کنید (ویدیو با کیفیت‌های مختلف یا فقط صدا)
4. زبان زیرنویس را انتخاب کنید (اختیاری)
5. تیک "دانلود به عنوان پلی‌لیست" را بزنید اگر لینک پلی‌لیست است
6. روی دکمه "شروع دانلود" کلیک کنید

### ویژگی‌های رابط وب

- **🔍 بررسی لینک:** نمایش اطلاعات ویدیو شامل عنوان، آپلودر، مدت زمان و تامبنیل قبل از دانلود
- **تشخیص خودکار پلی‌لیست:** اگر لینک پلی‌لیست باشد، به صورت خودکار تشخیص داده شده و تعداد ویدیوها نمایش داده می‌شود
- **وضعیت زنده:** مشاهده پیشرفت دانلود به صورت درصد و سرعت
- **تاریخچه:** لیست دانلودهای انجام شده
- **چند دانلود همزمان:** امکان شروع چندین دانلود به صورت همزمان
- **پشتیبانی از پلی‌لیست:** دانلود تمام ویدیوهای یک پلی‌لیست

## فرمت‌های قابل دانلود

| فرمت | توضیحات |
|------|---------|
| best | بهترین کیفیت ویدیو + صدا (ادغام شده در MP4) |
| 720p | کیفیت HD 720p |
| 480p | کیفیت استاندارد 480p |
| 360p | کیفیت پایین 360p |
| mp3  | فقط صدا با کیفیت 320kbps |
| m4a  | فقط صدا با فرمت M4A |

## نکات مهم

1. **ویدیوهای محدود شده:** برای دانلود ویدیوهایی که نیاز به لاگین دارند، باید از کوکی استفاده کنید (در حال توسعه)
2. **پلی‌لیست‌های بزرگ:** دانلود پلی‌لیست‌های بزرگ ممکن است زمان‌بر باشد
3. **فضای ذخیره‌سازی:** مطمئن شوید فضای کافی برای دانلود دارید

## عیب‌یابی

### خطای ffmpeg
اگر خطای مربوط به ffmpeg دریافت کردید، مطمئن شوید که نصب شده است:
```bash
ffmpeg -version
```

### مشکل در دانلود پلی‌لیست
- مطمئن شوید لینک پلی‌لیست صحیح است
- تیک "دانلود به عنوان پلی‌لیست" را زده باشید
- برخی پلی‌لیست‌ها ممکن است محدود باشند

### باز نشدن مرورگر
اگر مرورگر به صورت خودکار باز نشد، به آدرس نمایش داده شده در ترمینال بروید (مثلاً `http://localhost:5000`)
